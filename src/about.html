Qué puedes hacer

  • Grabar una pantalla completa, una ventana o una porción de una pantalla.
  • Tomar una imagen de la fuente seleccionada.
  • Incluir el micrófono, el sonido de Windows o ambos en un video.
  • Elegir el tamaño original o limitar la salida a 1080p, 720p o 480p.
  • Iniciar al momento o usar una cuenta atrás de 3, 5 o 10 segundos.
  • Generar subtítulos automáticamente al guardar una grabación con audio.
  • Recuperar capturas interrumpidas y reintentar su guardado.

Cómo hacer una captura

  1. Elige Video o Imagen y selecciona una pantalla o ventana.
  2. Para grabar solo una zona, elige una pantalla y pulsa Capturar una porción.
  3. Ajusta el formato, el tamaño y la cuenta atrás. En video, elige también las fuentes de audio.
  4. Inicia la captura. En video, pulsa Detener cuando termines.
  5. Espera el guardado y, si hay audio, la transcripción. La aplicación muestra el resultado y permite reintentar si algo falla.

Transcripción automática

Las grabaciones con audio generan un archivo .srt junto a la captura final. Esto también aplica al original WebM y a las animaciones GIF obtenidas de una grabación con sonido. Las capturas sin audio no generan subtítulos.

La primera vez se descarga un modelo de reconocimiento de voz de aproximadamente 57 MiB. Después, la transcripción funciona en este equipo sin enviar el audio a un servicio externo. El tiempo que tarda depende de la duración y del equipo.

El reconocimiento puede cometer errores y depende de la claridad del audio. Si no se detecta voz, el archivo de subtítulos puede quedar vacío. Si el proceso se interrumpe, el reintento comienza desde el video original.

Dónde se guarda y cómo recuperar

La carpeta predeterminada es Videos\WinScreenRecorder. Puedes cambiarla en Configuración. Si un nombre ya existe, la aplicación genera otro para conservar los archivos anteriores.

Cada grabación escribe su original en la subcarpeta Recuperación de la ubicación configurada. Si la aplicación se interrumpe, al volver a abrirla aparece un aviso para revisar las capturas pendientes en una ventana independiente.

Desde esa ventana puedes continuar el guardado o descartar una captura. El original se conserva hasta que el video y, cuando corresponda, los subtítulos se guardan correctamente, o hasta que lo descartas expresamente.

Qué se puede recuperar

Un video interrumpido mientras se grababa se intenta reparar con los fragmentos que llegaron al disco. La recuperación depende de que puedan leerse y no siempre es posible. La aplicación no graba mientras está cerrada; cada nueva captura inicia un archivo independiente.

Ventana, vista compacta y bandeja

Usa la vista compacta para tener los controles en una barra pequeña. Puedes alternarla con Ctrl + Shift + M.

Cerrar la ventana principal la oculta en el área de notificación de Windows. Desde el icono puedes volver a abrirla, consultar el estado y acceder a las grabaciones por recuperar. El texto al pasar el cursor y el menú indican si está grabando, transcribiendo, convirtiendo o guardando.

Para cerrar el programa, elige Salir en el menú del icono. Si hay una captura pendiente, Conservar y salir permite continuar después. También puedes activar el inicio con Windows desde Configuración; la aplicación se inicia oculta en la bandeja.

Privacidad, requisitos y límites

  • Aplicación de escritorio para Windows 10 y 11 de 64 bits.
  • La captura, la conversión y la transcripción se procesan localmente. El audio no se envía a un servicio de transcripción.
  • Se necesita Internet para la primera descarga del modelo de voz y espacio libre para los originales y las salidas.
  • El sonido de Windows depende del soporte de captura de audio disponible. Las imágenes y los GIF no contienen una pista de sonido.
  • Si la escritura al disco se retrasa, la grabación se pausa automáticamente hasta procesar los datos pendientes. El contador excluye esa pausa.
  • La velocidad y calidad de conversión dependen del equipo, la fuente y el tamaño de la captura.
